# Rúbricas de evaluación

## Evaluación diaria — 10 puntos

| Criterio | Máximo |
|---|---:|
| Comprensión conceptual | 3 |
| Terminología académica | 2 |
| Aplicación práctica | 3 |
| Justificación oral | 2 |

## Diagnóstico por materia — 10 puntos

| Nivel | Interpretación |
|---|---|
| 9–10 | Dominio sólido y defendible |
| 7–8,9 | Buen dominio; requiere precisión o práctica |
| 5–6,9 | Conocimiento parcial o inestable |
| 3–4,9 | Base débil |
| 0–2,9 | Requiere estudio desde fundamentos |

El diagnóstico no se usa para aprobar o desaprobar; se usa para redistribuir horas.

## Caso escrito — 100 puntos

| Área | Puntaje |
|---|---:|
| Comprensión del problema y alcance | 10 |
| RF, RNF y reglas | 15 |
| Casos de uso y UML | 15 |
| Arquitectura y diseño | 10 |
| POO y Java | 15 |
| Estructuras de datos | 10 |
| Base de Datos | 15 |
| Comunicaciones | 10 |

## Defensa oral — 100 puntos

| Criterio | Puntaje |
|---|---:|
| Precisión conceptual | 25 |
| Terminología académica | 20 |
| Justificación de decisiones | 25 |
| Relación entre materias | 20 |
| Claridad y orden | 10 |

## Regla de recuperación

- Nota menor a 6: recuperación obligatoria.
- Nota entre 6 y 7,9: repaso dirigido.
- Nota de 8 o más: mantener mediante preguntas espaciadas.
- Un tema no se cierra hasta alcanzar `Aplicado` y luego `Defendible oralmente`.
