# Glosario académico vivo

Este glosario debe crecer durante el estudio. Las definiciones se mantienen breves y alineadas con los materiales.

## Análisis y Diseño

- **Modelo:** simplificación de la realidad utilizada para visualizar, especificar, construir o documentar un sistema.
- **Metodología:** conjunto de fases, procedimientos, reglas, técnicas, herramientas y documentación que guía el desarrollo.
- **PUD:** proceso de desarrollo dirigido por casos de uso, centrado en la arquitectura, iterativo e incremental.
- **Iteración:** recorrido planificado de actividades que produce un resultado verificable.
- **Incremento:** crecimiento del producto obtenido como resultado de una iteración.
- **Artefacto:** información creada, modificada o utilizada durante el desarrollo.

- **Método:** forma técnica de construir o realizar una parte del sistema.
- **Técnica:** procedimiento estructurado y repetible para alcanzar una tarea específica.
- **Herramienta:** soporte automatizado o semiautomatizado para métodos y técnicas.
- **Fase:** período del ciclo del PUD con un objetivo principal y un hito de cierre.
- **Inicio:** fase que define alcance, viabilidad, casos críticos, riesgos y arquitectura inicial.
- **Elaboración:** fase que detalla la mayoría de los casos de uso y establece la línea base de arquitectura.
- **Construcción:** fase en la que la arquitectura crece hasta convertirse en el sistema completo.
- **Transición:** fase en la que el producto se prueba con usuarios, se corrige, se entrega y se acompaña su adopción.
- **Requerimiento funcional:** servicio o comportamiento que el sistema debe proporcionar.
- **Requerimiento no funcional:** restricción o propiedad que limita o condiciona la solución.
- **Actor:** rol externo que interactúa con el sistema.
- **Caso de uso:** secuencia de acciones que entrega un resultado de valor a un actor.

## Programación Orientada a Objetos

- **Objeto:** entidad con estado, comportamiento e identidad.
- **Clase:** plantilla o abstracción que define estructura y comportamiento comunes.

- **Estado:** conjunto de valores actuales de los atributos de un objeto.
- **Comportamiento:** operaciones mediante las cuales un objeto actúa, reacciona o cambia su estado.
- **Identidad:** propiedad que permite distinguir un objeto de todos los demás.
- **Constructor:** operación especial que crea un objeto e inicializa su estado.
- **Modificador de acceso:** palabra que controla la visibilidad de una clase o miembro.
- **Encapsulamiento:** separación de la interfaz pública y la implementación interna.
- **Herencia:** mecanismo por el que una subclase adquiere y especializa miembros de una superclase.
- **Polimorfismo:** capacidad de responder de manera diferente ante una misma operación según el objeto.
- **Abstracción:** selección de características esenciales y omisión de detalles irrelevantes.
- **Clase abstracta:** clase no instanciable destinada a proporcionar estructura y comportamiento común.
- **Interfaz:** contrato de operaciones que una clase se compromete a implementar.

## Algoritmos y Estructuras

- **TDA:** conjunto de datos y operaciones definido por su interfaz, independientemente de su implementación.
- **Pila:** estructura LIFO; el último elemento ingresado es el primero en salir.
- **Cola:** estructura FIFO; el primer elemento ingresado es el primero en salir.
- **Nodo:** elemento que contiene información y una o más referencias a otros nodos.
- **Lista enlazada:** estructura formada por nodos vinculados mediante referencias.
- **Iterador:** mecanismo para recorrer los elementos de una colección en un orden definido.

## Base de Datos

- **Relación:** representación tabular formada por atributos y tuplas.
- **Tupla:** fila de una relación.
- **Atributo:** columna que representa una propiedad.
- **Dominio:** conjunto de valores válidos para un atributo.
- **Grado:** cantidad de atributos de una relación.
- **Cardinalidad:** cantidad de tuplas de una relación.
- **Normalización:** proceso de descomposición de relaciones para disminuir redundancia y anomalías.
- **Álgebra relacional:** conjunto formal de operaciones sobre relaciones.

## Comunicaciones

- **Protocolo:** conjunto de reglas que permite el intercambio de información entre entidades.
- **OSI:** modelo de referencia de siete capas para describir funciones de comunicación.
- **TCP/IP:** arquitectura de protocolos utilizada para la interconexión de redes.
- **Encapsulamiento:** agregado de información de control a los datos al descender por las capas.
- **PDU:** unidad de datos propia de una capa de protocolo.
- **LAN:** red de área local.
- **WAN:** red de área extensa.
- **Topología:** disposición física o lógica de los elementos de una red.
