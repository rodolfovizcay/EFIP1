# Materia 3 — Algoritmos y Estructuras de Datos

## Objetivo para el EFIP

Elegir, explicar y representar la estructura adecuada, además de escribir las operaciones esenciales en Java.

## Secuencia de estudio

1. TDA, estructuras estáticas y dinámicas.
2. Arreglos.
3. Nodos.
4. Pilas con vector.
5. Pilas enlazadas.
6. Colas con vector.
7. Colas enlazadas.
8. Lista simple.
9. Lista doble.
10. Lista circular.
11. Lista ordenada.
12. Iteradores.
13. Inserción.
14. Shellsort.
15. Mergesort.
16. Quicksort.

## Método de dominio

Para cada estructura:

1. Definición.
2. Dibujo.
3. Operaciones.
4. Implementación.
5. Complejidad o costo relativo cuando la fuente lo permita.
6. Caso de uso.
7. Defensa de la elección.
