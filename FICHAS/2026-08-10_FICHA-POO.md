# Ficha de estudio — Fundamentos de POO

## Paradigma

La POO divide el problema en objetos que poseen características y comportamientos y que colaboran mediante mensajes.

## Clase y objeto

```text
Clase  = plantilla o definición de un tipo; describe estructura y comportamiento común
Objeto = instancia concreta, real o abstracta, con un papel en el dominio
```

## Tres propiedades de un objeto

| Propiedad | Definición |
|---|---|
| Estado | Valores actuales de los atributos |
| Comportamiento | Operaciones o métodos que puede realizar |
| Identidad | Propiedad que permite distinguir un objeto de otro similar |

Un identificador persistente puede representar la identidad, pero la identidad no se reduce solamente al valor de un campo `id`.

## Componentes

```text
Atributo    = dato que describe al objeto
Método      = operación que representa su comportamiento
Constructor = operación especial que crea/inicializa el objeto
```

## Encapsulamiento

Oculta los detalles internos y obliga a interactuar con el objeto mediante una interfaz controlada. Habitualmente se protegen los atributos y se publican métodos.

## Modificadores de acceso

| Modificador | Acceso principal |
|---|---|
| `public` | Desde cualquier clase |
| `private` | Solo desde la propia clase |
| `protected` | Propia clase, paquete y subclases según las reglas de Java |
| sin declarar | Clases del mismo paquete |

## Ejemplo

```java
public class OrdenTrabajo {
    private int numero;
    private String descripcion;
    private String estado;

    public OrdenTrabajo(int numero, String descripcion) {
        this.numero = numero;
        this.descripcion = descripcion;
        this.estado = "PENDIENTE";
    }

    public String getEstado() {
        return estado;
    }

    public void cambiarEstado(String nuevoEstado) {
        this.estado = nuevoEstado;
    }
}
```
