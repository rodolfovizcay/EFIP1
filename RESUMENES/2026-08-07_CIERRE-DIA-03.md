## 4. Respuesta oral consolidada

> Un arreglo es una estructura de capacidad definida cuyos elementos se acceden directamente mediante índices. Resulta apropiado cuando se conoce o limita la cantidad de elementos y se requiere acceso por posición. Una lista enlazada es una estructura dinámica formada por nodos; cada nodo contiene un dato y una referencia al siguiente. Para acceder a un elemento hay que recorrer los nodos, pero las inserciones y eliminaciones pueden realizarse modificando referencias sin desplazar todos los elementos. Como TDA, una estructura define los datos y las operaciones mediante una interfaz independiente de su implementación. En una base relacional, las órdenes se almacenan persistentemente en una relación como `ORDEN_TRABAJO`. Cada fila es una tupla y cada columna un atributo. Su grado es la cantidad de atributos y su cardinalidad la cantidad de filas. `id_ot` puede ser la clave primaria y `id_sector` una clave foránea que referencia `SECTOR`. Cuando la aplicación consulta la base, puede crear objetos en memoria y organizarlos temporalmente en arreglos o listas según las operaciones necesarias.

## 5. Ejemplo relacional consolidado

```text
ORDEN_TRABAJO(
    id_ot,
    descripcion,
    prioridad,
    estado,
    id_sector
)
```

```text
Relación: ORDEN_TRABAJO
Cabecera: {id_ot, descripcion, prioridad, estado, id_sector}
Grado: 5
Cardinalidad: cantidad de órdenes almacenadas
Clave primaria: id_ot
Clave foránea: id_sector → SECTOR.id_sector
Dominio prioridad: {BAJA, MEDIA, ALTA}
Dominio estado: conjunto de estados permitidos
```

## 6. Inserción al inicio

Lista original:

```text
cabeza → A → B → C → null
```

Pasos:

```text
nuevo.siguiente = cabeza
cabeza = nuevo
```

Resultado:

```text
cabeza → X → A → B → C → null
```

Si primero se reemplaza `cabeza` sin conservar la referencia anterior, puede perderse el acceso a toda la lista original.
