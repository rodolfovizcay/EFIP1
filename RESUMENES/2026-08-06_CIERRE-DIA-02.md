## 3. Conceptos que todavía requieren recuperación

### PUD

```text
Inicio       → alcance y viabilidad
Elaboración  → línea base estable de arquitectura
Construcción → producto completo
Transición   → beta, correcciones, formación y entrega
```

### Iteración e incremento

```text
Iteración = trabajo planificado o miniproyecto.
Incremento = crecimiento del producto que queda al finalizar la iteración.
```

### Estado y comportamiento

```text
Estado = valores actuales.
Comportamiento = métodos.
```

### Identidad

> Es la propiedad que permite distinguir un objeto de cualquier otro. El ID puede ser una representación persistente de esa identidad.

### Sobrecarga y sobrescritura

```text
Sobrecarga:
mismo nombre + parámetros distintos.

Sobrescritura:
método heredado + misma signatura + nueva implementación.
```

## 4. Respuesta oral modelo consolidada

> Para desarrollar el módulo de Órdenes de Trabajo aplicaría el PUD. En Inicio definiría el problema, el alcance, los actores, los casos de uso críticos, los riesgos y una arquitectura inicial. En Elaboración detallaría la mayoría de los casos de uso, como crear, listar, modificar, despachar y cambiar estado, y estabilizaría la arquitectura. En Construcción implementaría y probaría esos casos de uso hasta obtener el producto completo, y en Transición realizaría pruebas con usuarios, correcciones, formación y despliegue. El PUD está dirigido por casos de uso, centrado en la arquitectura y es iterativo e incremental. `OrdenTrabajo` sería una clase y una OT concreta sería un objeto. Su estado estaría dado por valores como `PENDIENTE` y prioridad `ALTA`, mientras que su comportamiento estaría representado por métodos como `despachar()` y `cambiarPrioridad()`. La identidad permite distinguir cada OT, y el encapsulamiento mantiene sus atributos privados y expone métodos públicos que validan los cambios permitidos.

## 5. Código Java corregido del ejercicio

```java
public class OrdenTrabajo {

    private int id;
    private String descripcion;
    private String prioridad;
    private String estado;

    public OrdenTrabajo(
            int id,
            String descripcion,
            String prioridad) {

        this.id = id;
        this.descripcion = descripcion;
        this.estado = "PENDIENTE";
        cambiarPrioridad(prioridad);
    }

    public void iniciar() {
        this.estado = "EN_EJECUCION";
    }

    public void cambiarPrioridad(String nuevaPrioridad) {
        if ("ALTA".equals(nuevaPrioridad)
                || "MEDIA".equals(nuevaPrioridad)
                || "BAJA".equals(nuevaPrioridad)) {
            this.prioridad = nuevaPrioridad;
        }
    }

    public String getEstado() {
        return this.estado;
    }
}
```
