# 5. Clasificación de errores

| Tipo | Descripción |
|---|---|
| conceptual | regla o modelo comprendido incorrectamente |
| terminológico | idea general correcta con término equivocado |
| práctico | procedimiento o cálculo mal ejecutado |
| sintáctico | estructura de código/SQL incorrecta |
| justificación | decisión sin criterios, riesgo o consecuencia |

Estado:

```text
abierto      → todavía falla
corregido    → resuelto con ayuda o evidencia insuficiente para consolidar
consolidado  → reaparece y se resuelve autónomamente
reabierto    → un error corregido/consolidado vuelve a aparecer
```
