# 5. Estudio de Comunicaciones

## Bloque A — Sistema y protocolo

Debés poder explicar:

- objetivo de una comunicación;
- fuente, transductores, transmisor, medio, receptor y destino;
- ETD y ETCD;
- protocolo;
- sintaxis, semántica y temporización.

## Bloque B — OSI

Construir de memoria esta tabla:

| Capa | Función | Ejemplo |

| Aplicación | | |
| Presentación | | |
| Sesión | | |
| Transporte | | |
| Red | | |
| Enlace | | |
| Física | | |

No avanzar hasta poder completarla sin mirar.

## Bloque C — TCP/IP

Explicar:

- las cinco capas del material;
- correspondencia con OSI;
- diferencia entre modelo de referencia y arquitectura de protocolos.

## Bloque D — Encapsulamiento

Dibujar:

```text
Aplicación
  ↓
Transporte
  ↓
Internet/Red
  ↓
Acceso/Enlace
  ↓
Física
```

Anotar qué información identifica:

- proceso;
- equipo/red;
- interfaz local;
- medio.
